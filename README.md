# Mtaani Dating - Kenya Location-Based Matchmaking

Location-based online dating platform for people in Kenya.

## Features (Prototype)
- Home with GPS location request
- Profile setup (saved locally)
- Discover page with swipe-like like/pass
- Matches list
- Mock Kenyan users from Nairobi, Mombasa, Kisumu, Kiambu
- County filters ready

## Tech
- Next.js 16 + TypeScript + Tailwind
- Deployable to Netlify
- Frontend prototype (use Supabase/Firebase for real backend, auth, real-time chat, photo uploads)

## Localization
- Counties: Nairobi, Mombasa, Kisumu, Kiambu, etc.
- Tribe, religion, interests
- Sheng-friendly bios
- M-Pesa ready for premium features

## Deploy
1. Connect this repo to Netlify
2. Build command: `npm run build`
3. Or use Netlify CLI / automatic deploys

Live prototype ready for further development.
